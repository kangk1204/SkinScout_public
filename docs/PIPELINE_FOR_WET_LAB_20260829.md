# Wet-lab 연구자를 위한 분석 파이프라인 — 측정에 근거한 구성

- 작성일: 2026-08-29 (Asia/Seoul)
- 근거: `docs/RERANK_EXPERIMENT_20260828.md` (15화합물 28쌍, leave-query-out),
  `docs/RESEARCHER_GUIDE.md` (구간별 회수율), `docs/COVERAGE_ROUTES_20260824.md`

이 문서는 "무엇을 어떤 순서로 계산하고, 연구자는 무엇을 어떤 순서로 읽는가"를
한 장으로 정리한다. 모든 선택에 측정된 근거를 붙였다.

## 계산 순서

```
입력 (이름 / SMILES / 그리기 / SDF)
  ↓  적용범위 판정 + 2D 구조 확인          ← 실행 전에 차단·경고
안전성 (ADMET 49 · 감작 3모델 · 구조경보)   ← triage 전용, 미검증
  ↓
Daina-Zoete 리간드 유사도 → 전체 프로테옴 순위
  ↓  상위 256개 선택                        (동결된 공개 계약)
AutoGrid → AutoDock-GPU → GNINA (pose 재채점)
  ↓
구조 오버레이 → daina_structural_targets.csv   (유사도 순서, 계약 산출물)
  ↓  밴드 재정렬 (상위 10위 고정, 11–50위만)
     → top50_band_reranked.csv                (연구자가 보는 순서)
  ↓
3D 뷰어 + 판정 보고서 + 다운로드 번들
```

## 왜 이 구성인가 — 선택별 근거

### 1. 순위는 유사도가 정한다

| 방법 | 평균 순위 | top-30 |
|---|---:|---:|
| Daina 유사도 | 43.2 | 14/28 |
| AutoDock ΔG | 100.2 | 5/27 |
| GNINA | 79.6 | 12/27 |

무작위 기대는 128이다. **ΔG는 순위 근거로 쓸 수 없다.** 도킹을 1차 순위로 삼는
설계는 측정으로 기각된다.

### 2. 도킹은 11–50위 구간에서만 순서를 바꾼다

| Daina 순위 | n | 재랭킹 결과 |
|---|---:|---|
| 1–10위 | 8 | **8건 전부 악화** |
| 11–50위 | 13 | **11건 개선** |
| 51위 이하 | 7 | 5건 악화 |

상위권은 유사도가 이미 옳다 — Capsaicin–TRPV1 1위→41위, alpha-Arbutin–TYR 2위→44위로
망가진다. 중간 구간은 유사도가 애매하고 구조가 판별력을 갖는다 —
Retinol의 RAR 세 아형이 25/27/31위 → 11/12/13위로 올라온다.

결과: 평균 43.2 → 38.5, top-30 14/28 → 20/28, **Wilcoxon p < 0.01**.
임계값 조합 33개 중 26개, 화합물 제외 14변형 전부에서 유의하다.

### 3. 계약 산출물은 건드리지 않는다

`daina_structural_targets.csv`는 유사도 순서를 유지한다. 재정렬은 옆 파일로 나가고
**모든 행이 `daina_rank`를 갖는다.** 뷰어의 `유사도 순위` 열이 그 값이며, 표의 순위와
다르면 도킹이 움직인 것이다. 두 순서를 언제든 대조할 수 있다.

### 4. 입력은 실행 전에 막는다

수 시간짜리 실행을 시작하기 전에 RDKit이 읽은 분자를 2D로 보여주고 적용범위를 판정한다.
펩타이드·혼합물·고분자·계면활성제·자외선차단제는 시작 버튼이 비활성화된다.
물성 경고(검증 패널 범위 밖)는 막지 않고 알리기만 한다.

### 5. 안전성은 triage로만 쓴다

ADMET 49 엔드포인트와 감작 3모델 합의가 산출되지만 **`results/eval/` 어디에도
실측 대조 자료가 없다.** 표적 예측은 "언제 믿을지" 말할 수 있지만 안전성은 그럴 수 없다.
OECD 시험을 대체하지 않는다.

## 연구자가 읽는 순서

1. **판정 배너** — PASS는 커밋된 44개 실행에서 한 번도 나온 적이 없다.
   REVIEW 사유가 *안전성 신호*인지 *장부 문제*인지 구분해 읽는다
2. **최근접 유사도** — 이 값이 모든 것을 결정한다

   | 유사도 | 실측 (15화합물) | 어떻게 쓰나 |
   |---|---|---|
   | ≥ 0.6 | 7/7 화합물이 top-30 | 상위 몇 개를 실험 후보로 |
   | 0.4–0.6 | 2/6 | 참고만, 문헌 교차확인 |
   | < 0.4 | 1/2 | 이 도구가 답할 수 없음 |

3. **`조회` / `예측`** — 조회는 이미 알려진 상호작용을 찾아온 것이라 새 정보가 아니다
4. **`유사도 순위` 열** — 표의 순위와 다르면 도킹이 움직인 표적이다
5. **`수용체 한계`** — 금속 보조인자 누락·GPCR 비활성 상태. 이 표시가 있으면
   도킹 점수가 낮아도 결합이 약하다는 근거가 되지 않는다
6. **3D 구조** — 결과 화면에 내장. pose가 포켓 밖이면 점수를 믿지 않는다

## 이 파이프라인이 답할 수 없는 것

- **표적 20,204개 중 약 23%(4,727개)만 채점된다.** 나머지는 0점이 아니라
  **출력에 나타나지 않는다** — 참조 리간드가 없어 채점 시도조차 되지 않는다.
  재랭킹은 이미 후보에 든 256개 안의 순서만 바꾼다. Daina가 놓친 표적은
  어떤 방법으로도 복구되지 않는다 — 이것이 진짜 천장이다
- AutoGrid 격자는 수용체 15,038개 중 13,339개(88.7%)에만 만들어졌다
- 도킹 점수는 화합물 간 비교가 불가능하다(큰 분자일수록 ΔG가 자동으로 낮다)
- `09_report` 9패널 리포트는 **한 번도 생성된 적이 없다**

## 다음에 투자할 곳

순위에서 얻을 수 있는 이득의 크기가 이번에 드러났다(top-30 14→20/28). 실질적이지만
천장을 올리지는 않는다.

**수용체 배경 정규화(Route C)는 2026-08-29에 측정했고 기각했다** —
`docs/COVERAGE_ROUTE_C_RETIRED_20260829.md`. 편향은 제거하지만 회수를 개선하지 않는다
(19쌍, 개선 9 / 악화 10, p=0.83).

남은 경로는 **Route B(포켓 클러스터 전달)**이며, 커버리지를 0.223 → 0.326으로 올리고
dual-cold 표적 98개 중 16개에 도달하는 것으로 원 문서에 측정돼 있다. 다만 전제 조건이
있다 — 현재 dev pocket-cold 비율이 2.1%뿐이라 **적정 규모의 pocket-cold 패널을 먼저
만들어야** 순환논증을 피할 수 있다. 그 패널 구축이 커버리지 작업의 실제 첫 단계다.

## 설정

```yaml
docking:
  fast_mode_daina_top_n: 256      # 동결된 공개 계약
  fast_mode_rerank_keep: 10       # 1..10위는 유사도 순서 고정
  fast_mode_rerank_band: 50       # 11..50위만 RRF로 재정렬
  fast_mode_dock_band_only: true  # 그 밴드만 도킹 (35분 → 6분)
```

`fast_mode_rerank_band ≤ fast_mode_rerank_keep`으로 두면 재정렬이 꺼지고 순수
유사도 순서가 된다.

**2026-08-30부터 도킹은 밴드 40개만 한다.** 머리는 고정이고 51위 아래는 재정렬에
쓰이지 않으므로, 11–50위만 격자를 만들고 도킹한다. 결과는 동일하고(평균 38.5,
top-30 20/28) 화합물당 도킹이 실측 약 35분에서 6분으로 줄어든다.

선택 256개는 동결 계약이라 그대로다. 밴드 밖 표적은 순위표에 남되 상태가
`structure_not_requested`이며, 이는 "실패"가 아니라 **"요청하지 않았다"**는 뜻이다.
끄려면 `fast_mode_dock_band_only: false`.
