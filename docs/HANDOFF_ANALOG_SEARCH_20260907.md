# 유사체 탐색 전달본 — 알려진 성분에서 출발해 비슷한 원료 찾기

작성 2026-09-07. 이 문서의 수치는 모두 이 저장소에서 실제로 재서 얻은 것이고,
어디서 나왔는지 함께 적었습니다. 재보지 않은 것은 적지 않았습니다.

## 이 도구로 할 수 있는 일

**알려진 활성 성분 하나를 넣으면 구조가 비슷한 화장품 원료를 순위로 돌려줍니다.**
표적 예측이나 신규 물질 발굴이 아니라, 이미 좋다고 알려진 것의 **대체·유사 원료**를
찾는 용도입니다. 측정된 성능이 이 용도에 맞습니다.

## 바로 쓰는 법

```bash
python scripts/alternative_ingredients.py \
  --smiles "C1=CC(=CN=C1)C(=O)N" \
  --exclude-self --limit 30 \
  --out-csv niacinamide_analogs.csv
```

### 설정에 손대지 마세요 (측정으로 정해진 값입니다)

- **`--min-similarity` 는 0 그대로.** 진짜 대체 관계인 원료쌍의 유사도 중앙값이
  0.145 입니다. 0.25 로 올리면 정답쌍의 60% 가 사라집니다. 유사도는 **정렬**에는
  최고이고 **문턱**으로는 최악입니다.
- **`--require-core` 는 끄고 두세요.** 켜면 회수율이 무너집니다. `core_grade` 열은
  거르는 데 쓰지 말고 읽는 데 쓰세요.
- **`--with-evidence` 는 켜세요.** 이 모듈에서 유일하게 구조 추정이 아니라 실제
  활성 측정에 근거한 열입니다.

## 브라우저로 쓰는 법 (권장)

명령줄을 몰라도 됩니다. 담당자 기계에서 워크벤치를 띄우고, 공동연구자는 브라우저로
붙습니다.

**공동연구자 컴퓨터에 직접 깔 때**

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/kangk1204/SkinScout_public/main/install_skinscout.sh) \
  --profile analog --analog-bundle <번들 주소>
```

전체 설치는 Stage 0 데이터 125 GB 를 만드는데, 대체소재 검색이 여는 것은 그중
원료 표 하나(13 MB)와 별도 데이터 둘뿐입니다. `--profile analog` 은 그 무거운
단계를 건너뛰고 대신 만들어 둔 번들(약 115 MB)을 받습니다. GPU 도 필요 없습니다.

번들은 담당자가 만들어 전달합니다:

```bash
python scripts/build_analog_bundle.py --out dist/
# dist/skinscout-analog-bundle.tar.gz 와 .manifest.json 을 함께 넘기세요
```

번들에는 등재 원료 구조, 원료별 ADMET 예측, 활성 측정 인덱스가 들어 있습니다.
저장소에는 없습니다 - 인덱스는 ChEMBL·BindingDB 원본 55 GB 에서 106 만 리간드를
지문화한 결과라 받는 쪽이 다시 만들 수 없기 때문입니다. 받는 쪽은 해시를 대조한
뒤에만 풀고, 어긋나면 한 바이트도 남기지 않습니다.

**띄우는 쪽 (담당자)**

```bash
# 같은 기계에서만 쓸 때
python3 scripts/run_workbench.py

# 다른 기계에서 붙을 때 - 인증이 자동으로 켜집니다
python3 scripts/run_workbench.py --host 0.0.0.0 --port 8080
```

두 번째 경우 접속 토큰이 아래 파일에 만들어집니다. 이 값을 공동연구자에게
따로 전달하세요.

```
~/.local/share/skinscout/secrets/workbench-access.token
```

인증 없이 외부 주소로 열려고 하면 서버가 시작을 거부합니다(실측 확인).
다만 **통신은 암호화되지 않은 HTTP** 입니다. 믿을 수 있는 사내망에서만 쓰고,
그 밖이면 SSH 터널을 쓰세요.

```bash
ssh -L 8080:localhost:8080 <담당자계정>@<서버>
# 그 뒤 브라우저에서 http://localhost:8080
```

**쓰는 쪽 (공동연구자)** — 왼쪽 `03 대체소재 검색`으로 들어가서:

1. 성분 이름을 넣거나(`레티놀`, `Niacinamide`, `salicylic acid` — 오프라인
   사전이라 인터넷을 쓰지 않습니다) SMILES 를 직접 넣습니다
2. `대체소재 후보 찾기`
3. 표의 `3D` 단추로 구조를 돌려 보고, `CSV로 내려받기` 로 저장합니다

표 위의 **`이 표가 말하지 않는 것`** 일곱 줄을 먼저 읽으세요. 이 도구가 무엇을
판정하지 **않는지**가 거기 적혀 있습니다.

### 이 패널에서 드러난 함정 셋

**1. 구조가 가까워도 대체재가 아니다 — 글리콜산 → 옥살산.** 1위가 옥살산인데
이것은 부식성 물질이지 각질제거제가 아닙니다. 그런데 **신고 배합목적 열이 바로
말해 줍니다**: `ANTICORROSIVE; CHELATING; ANTIPERSPIRANT; DEODORANT` - 각질제거가
없습니다. 3위 MALIC ACID(사과산)가 실제 AHA 입니다. **유사도·유지율만 보지 말고
신고 배합목적을 같이 보세요.** 이 표에서 가장 중요한 한 줄입니다.

**2. 핵심구조 유지 후보가 0건이어도 점수는 나온다 — 바쿠치올.** 등재 원료
7,484종에 바쿠치올의 핵심을 유지한 것이 하나도 없습니다(`유지후보 0`). 그런데도
1~3위가 종합 0.80 으로 뜹니다 - 리날룰 계열 모노테르펜이고 기능적으로 무관합니다.
**표 위의 `유지후보 N건`을 먼저 보세요.** 0이면 그 목록은 "가장 덜 다른 것"이지
대체 후보가 아닙니다.

**3. 등재됐다고 쓸 수 있는 것이 아니다 — 고쳤습니다.** 이 패널을 돌렸을 때
트리클로산의 2위로 `Nitrofen`(금지 제초제)이, 글리콜산의 2위로
`Methoxyacetic acid`(생식독성)가 나왔습니다. 둘 다 CosIng 에 항목은 있지만
**신고 배합목적이 비어 있습니다** - 규제 목록에 이름만 올라 있는 물질입니다.
실측으로 7,484종 중 **1,215종(16.2%)**이 그렇고, 그 안에 메타조신(마약성
진통제), 헥사클로로 살충제, 아세틸콜린 같은 것이 들어 있습니다.

그래서 화면이 **기본으로 숨기고, 몇 건을 숨겼는지 표 위에 적습니다.** 지우지는
않습니다 - "내 화합물이 금지 물질과 구조가 닮았다"는 사실 자체가 알 가치가
있으므로 `배합목적 미신고 물질도 보기`를 켜면 다시 나오고, 그때는 행에
`배합목적 미신고` 배지가 붙습니다.

거르는 것은 **점수를 매긴 뒤**입니다. 앞에서 거르면 백분위의 기준 집합이 바뀌어
같은 후보가 체크박스 하나로 다른 종합 점수를 받습니다.

고친 뒤 글리콜산의 2·3위가 **MALIC ACID(사과산)**과 **SODIUM MALATE** 로,
트리클로산의 2위가 **T-BUTYL METHYLPHENOXY PHENOL(DEODORANT)** 로 바뀌었습니다.

**2번도 화면에 반영했습니다.** 핵심구조 유지 후보가 0건이면 표 위에 "아래는
'가장 덜 다른 것'이지 대체 후보가 아닙니다"라고 상시 표시합니다.

끝났고, 안 본 후보가 "구조가 전혀 다름"으로 순위에 들어갔습니다. 상한을 600 초로
올려 끝까지 대조하게 했습니다. 보통 질의는 여전히 2~5 초입니다.

**라이브러리가 15배 늘어난 것이 이 용도에 가장 큰 변화입니다.** 원인은 구조 조회
캐시였습니다. PubChem 이 초당 5회를 넘기면 주는 일시적 503 을 "이 성분은 구조가
없다"로 영구 캐시해, 5만 항목 중 99% 가 잘못 굳어 있었습니다. 그래서
나이아신아마이드·레티놀·코직산·아데노신이 후보에 아예 없었습니다. 지금은 전부
있습니다.

## 남은 한계 — 그대로 알고 쓰세요

- **결합 자유에너지는 표적에 따라 결정되지 않습니다.** 5 ns 두 복제 실측:
  P11086 −22.5 ± 1.6, P52788 −15.6 ± 1.1 은 쓸 수 있지만 **Q14393 −15.4 ± 5.2** 는
  두 복제가 10.5 kcal/mol 벌어져 결합 세기를 말하지 못합니다. 원인은 리간드
  이탈이 아니라(두 복제 모두 포켓 안, 최소거리 2.0~2.2 Å) 포켓이 두 형태를 취해
  반데르발스 접촉이 달라진 것입니다.
- **CosIng 37,071 건 중 26,951 건은 여전히 구조가 없습니다.** 대부분 추출물·
  혼합물·고분자로 실제로 단일 구조가 없는 것들입니다. 찾는 원료가 결과에 없으면
  "그 원료가 나쁘다"가 아니라 "구조 비교 대상이 아니다"로 읽으세요.
- **활성 측정 근거가 있는 원료는 13.8% 뿐입니다** (1,035 / 7,484). 종합 점수의
  근거 축(가중치 25%)은 나머지 86% 에서 중앙값으로 채워집니다. 화면은 그 칸에
  `추정` 을 붙이고 표 위에도 몇 건이 실측인지 적지만, 기저율이 이렇다는 것을
  알고 읽으세요. 이것은 결함이 아니라 사실입니다 - ChEMBL·BindingDB 는 신약
  데이터베이스라 향료·유연제·계면활성제 같은 원료는 애초에 들어 있지 않습니다.
  (알려진 생리활성 원료는 정상적으로 붙습니다: 살리실산 13표적, 레스베라트롤
  53표적, 카페인 15표적, 레티놀 3표적 — 실측 확인.)
- **ADMET 예측은 7,484 종 전부에 있습니다**(2026-09-09 기준). 그 전에는 87.6%
  였는데, 예측이 실패해서가 아니라 캐시를 원본 표의 InChIKey 로 만들고 화면은
  정규화해 다시 계산한 InChIKey 로 조회해서 925 종이 영영 조인되지 않았습니다.
  키를 맞춰 다시 만들었습니다.
- **현재 모집단에서 잰 성능 수치가 없습니다.** 아래 "기준별 AUC" 절을 보세요.
  이것이 이 전달본의 가장 큰 공백입니다.
- **정답표가 좁습니다.** 대체 관계 57 쌍 중 47 쌍이 "같은 규제 부속서에 함께
  등재됨"이고, 32 쌍이 자외선차단제·19 쌍이 보존제입니다. 이 계열 밖에서의
  성능은 이 표로 보증되지 않습니다.

## 기준별 AUC — 처음으로 현재 모집단에서 쟀습니다 (2026-09-10)

507종 시절의 값(0.685 대 0.657/0.645/0.666)은 더 이상 인용하지 마세요. 아래가
지금 라이브러리에서 잰 값입니다.

**어떻게 쟀나.** 7,484종 전수는 며칠이 걸려 못 잽니다. 씨앗을 고정한 무작위 표본
**800종**을 뽑아 그 안에서 정답표를 만들고 재는 것을 **씨앗 3개**로 반복했습니다
(질의 677·668·690개). 무작위 표본은 기준 **사이의 비교**에 대해 편향되지 않습니다.
절대값은 모집단 크기에 따라 달라지므로 다른 표본과 나란히 놓지 마세요.

800종으로 정한 것은 그 위에서 `rdFMCS.FindMCS` 가 MemoryError 를 던지기 때문입니다.
특정 쌍의 문제가 아니라(가장 큰 질의 12개 × 후보 100개를 따로 돌리면 한 번도 나지
않습니다) 한 프로세스에서 100만 번 넘게 부르며 쌓이는 것입니다. 1,200종에서는
직렬로도 납니다.

| 기준 | 평균 AUC | 씨앗 3개 범위 | 우연 초과 질의 |
|---|---:|---|---:|
| 순위평균(세 기준 합침) | **0.631** | 0.626~0.640 | 83.4% |
| 파마코포어 | **0.627** | 0.618~0.634 | 80.9% |
| 분자 유사도(ECFP4) | 0.620 | 0.614~0.629 | 84.7% |
| **극성 기준선(구조 안 봄)** | **0.609** | 0.608~0.610 | 70.2% |
| 구조 유지율(MCS) | 0.603 | 0.600~0.608 | 76.7% |
| **크기 기준선(구조 안 봄)** | 0.586 | 0.577~0.594 | 67.1% |
| 난수 대조 | 0.499 | 0.498~0.501 | 49.5% |

난수 대조가 0.499로 나오므로 측정 도구 자체는 정상입니다.

### 읽어야 할 두 가지

**1. 예전 결론의 절반이 틀렸습니다.** "합친 순위가 세 기준 각각을 모두 이긴다"고
적혀 있었는데, 지금 모집단에서는 그렇지 않습니다(짝지은 Wilcoxon, Bonferroni 보정):

| 비교 | 평균차 | p (씨앗 3개 중 최대) |
|---|---:|---:|
| 합침 > 구조 유지율 | +0.030 | 2e-30 |
| 합침 > 분자 유사도 | +0.014 | 2e-08 |
| 합침 > 파마코포어 | +0.010 | **0.17 — 차이 없음** |

**파마코포어 하나만 써도 세 기준을 합친 것과 구분되지 않습니다.** 합치는 이득은
구조 유지율과 Tanimoto 를 상대로만 남습니다.

**2. 네 방법 모두 귀무 기준을 이기지 못합니다.** 질의마다 크기·극성 두 기준선 중
더 나은 쪽을 고른 것과 짝지어 비교하면:

| 방법 | 귀무 기준 대비 | p (최대) |
|---|---:|---:|
| 세 기준 합침 | **−0.026** | 3.3e-02 |
| 파마코포어 | −0.036 | 2.3e-02 |
| 분자 유사도 | −0.041 | 1.3e-05 |
| 구조 유지율 | **−0.056** | 2.2e-07 |

비교 대상이 "두 기준선 중 질의마다 좋은 쪽"이라 실제보다 센 상대입니다 - 단일
기준선과 평균만 견주면 합침(0.631)이 극성(0.609)·크기(0.586)보다 앞섭니다. 그래도
**구조를 전혀 보지 않는 기준을 확실히 이긴다고는 말할 수 없습니다.** 효과 크기도
전부 AUC 0.01~0.08 수준입니다.

### 이것이 뜻하는 것과 뜻하지 않는 것

정답표가 **"CosIng 에 신고된 배합목적이 겹치는가"**입니다. 그것은 "대체 가능한가"가
아니고, 배합목적은 화학 분류와 강하게 얽혀 있습니다(예: HAIR DYEING 은 대부분
방향족 아민). 그래서 이 표가 말하는 것은 **"신고 배합목적을 맞히는 과제에서는
구조 기준이 크기·극성보다 확실히 낫지 않다"**이지, "유사체 검색이 쓸모없다"가
아닙니다.

실제로 이 도구가 잘하는 일은 위 15종 패널이 보여 줍니다 - 비타민 C 유도체 셋,
비타민 E 에스터 셋, 레티노이드 계열을 정확히 찾아 옵니다. 그 일은 이 정답표가
재는 것과 다릅니다.

**그러니 이렇게 쓰세요.** 순위를 **가설을 좁히는 순서**로 쓰고, 그 순서가 크기·극성
같은 단순한 성질을 얼마나 반영하는지 알고 읽으세요. 표의 `유지율`·`유사도`·
`파마코포어` 세 열을 함께 보고, 신고 배합목적으로 걸러 내는 것이 지금으로서는
가장 확실한 필터입니다.

재현: `scripts/eval_alternative_criteria.py` 를 1,200종 표본으로 감싸 돌렸습니다
(씨앗 20260909·4242·8888, 워커 4개, 씨앗당 0.9~1.1분).

## 이 도구의 위치

가설을 좁히는 도구입니다. 실험 후보 목록을 만들 때 쓰고, 결합 여부를 판정하는
근거로는 쓰지 마세요. 저장소의 게이트도 비교 성능·SOTA 주장을 막아 두었습니다.
